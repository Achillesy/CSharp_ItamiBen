# ItamiBen — 痛みを知らせる

> **痛みを知らせる** —— 让你知道它有多疼。

一个会较真的番茄钟。先划定自己允许做的事，再承诺一段专注，整段时间里它盯着前台窗口。
一走神，那些分钟就是不算——休息区往后挪，你眼睁睁看着它越推越远。

不弹窗、不唠叨、也不恭喜你。就是一台笨到没法跟你讲条件的钟。

**状态：早期，但能跑。** macOS 上端到端验过，Windows 11 上也验过了（2026-09-18）：
前台程序名与标题、空闲判定、winmm 提示音、到点的提醒和它带的命令、单实例、几条调试查询，
以及 Inno Setup 安装包从编译到静默升级。

[English](./README.md)

## 跟别的番茄钟不一样在哪

多数番茄钟是「靠自觉的秒表」：你按下开始，25 分钟后它恭喜你，完全不管这期间你干了什么。
ItamiBen 会判。**只有当你真正看着的那扇窗口命中你事先写好的规则，那一秒才算数**——
事先写，不是事中改。

它**不依赖 ActivityWatch**：自己每秒读十次前台窗口，每秒往自己的数据库落一行。
（前作 ItamiTimer 建在 ActivityWatch 上，事实证明那个地基不适合干这件事，本项目是重做。）

ItamiBen 自己也**没有任何特例**：盯着它自己的钟面就是跑偏，跟盯着别的什么一样。

## 一轮是怎么走的

1. 选一个目标（**单选**，而且默认已经选中一个）。
2. 拖滑块——10 到 50 分钟，步长 5。它**没有数字也没有标签**，意义就在于靠猜。
3. 按 **Start**。从这一刻起，钟每秒读一次前台窗口。
4. 专注目标达成后是一段休息：`⌈专注 ÷ 5⌉` 分钟。

这一切都发生在一个**两小时的环**里。硬就硬在这儿：环是**墙上时间**，它不会伸长。
凡是没在专注的秒——跑偏、离开键盘、锁屏、甚至盯着 ItamiBen 自己——吃的是同一份预算：

    预算 = (120 − 休息) × 60 − 目标
    余量 = 预算 − (走过的秒 − 专注的秒)

余量见底，这一轮就结束。**没有任何办法把它赚回来。**

### 环上画的是什么

每一分钟是环上的一块桶板：

| 这一分钟发生了什么 | 长什么样 |
|---|---|
| 大部分时间在专注 | 高高的绿色桶板 |
| 部分专注 | 矮一些，颜色走绿 → 黄 → 红 |
| 跑偏 | 一块矮的红桶板 |
| 人不在（键鼠空闲满 3 分钟） | **空心虚线框**——时间确实过去了，但不怪你 |
| 什么都没采到 | 什么都不画 |

颜色和高度**故意编码同一个量**：一个给正常视觉，一个给所有人——红绿是最常见的色盲混淆对。

指针前方那块描边的区域是休息区。**那就是全部的惩罚**：每浪费一分钟它就往后挪一分钟，
你眼睁睁看着它跑远。

### 跑偏的时候

跑偏期间钟面每秒半反色翻一次，滴答声跟着起来。**除此之外什么都不发生。**
右上角的喇叭图标可以把跑偏的滴答静音。

## 窗口

无边框、置顶，所以它像挂在桌面上的钟，不像一个程序。**拖动要拖钟面**（可拖区域是圆的，
不是方的）。

- **在钟面上滚滚轮**拨黄色的闹钟针，一直滚会加速。
- **右键钟面**：置顶 · 强制滴答 · 闹钟到点跑命令 · 关闭窗口。
- **点那个小红圈**，瞄一眼 12 小时内的下一条提醒，只留 3 秒，纯读不改任何东西。
- 钟面下面那**七个骨牌**是星期几，倒下的是已经过去的那几天。
- **最底下那一栏**显示钟此刻读到的前台程序和窗口标题——**你的规则就是拿它来匹配的**。
- 齿轮开设置；图钉切置顶；第三个图标切明暗主题。

### 把窗口缩小，和让它透出后面的东西

`setting` 表里的两个键——跟智能体说，或者自己改：

```sql
UPDATE setting SET value = '"compact"' WHERE key = 'layout';
UPDATE setting SET value = '60'        WHERE key = 'opacityPercent';
```

`layout` 取 `standard`（宽 380）或 `compact`（宽 292）。`opacity` 取 0~100，
**只作用在钟面和卡片底色上**——按钮和文字保持实心，把它们一起调淡只会让人没法读。

**只在启动时读一次。**

## 怎么配置：把一个文件扔给 AI

配置住在四份 Markdown 文件里。**每一份都自带说明**——开头一段给你看的话，中间是给 AI 的
详细规矩，最后是标记好的配置块。

```
macOS    ~/Library/Application Support/ItamiBen/
Windows  %LOCALAPPDATA%\ItamiBen\
```

| 文件 | 管什么 |
|---|---|
| `rules.md` | 什么算工作 |
| `commands.md` | 这台机器可以被自动跑的全部命令，以及闹钟跑哪一条 |
| `schedule.md` | 周期提醒，标准 crontab 格式 |
| `layout.md` | 窗口多宽、多透 |

**把整个文件交给任意一个 AI** ——能操作文件的编码智能体，或者你粘贴进去的网页对话，
都一样——然后说你想要什么：

> 只有 VS Code 和标题里带 GitHub 的 Chrome 算工作。

> 工作日 9 点到 18 点，每小时提醒我起来动一动。

把它给回来的内容覆盖原文件就行。不用装任何东西，不用配置什么，
**也不需要第二份文档**——说明就在文件里。

每份旁边还有一个 `*.sample.md`，是完好的参考版，**每次启动都从程序里刷新一遍**。
哪天 AI 把你的文件改坏了，就拿它对照。

改完一分钟内生效。唯一的例外是 `layout.md`——它只在启动时读一次，文件里写着。

## 你的文件

都在 `~/Library/Application Support/ItamiBen/`（macOS）或 `%LOCALAPPDATA%\ItamiBen\`（Windows）。

| 文件 | 是什么 |
|---|---|
| `rules.md` `commands.md` `schedule.md` `layout.md` | 你的配置，归你改，程序永不覆盖 |
| `*.sample.md` | 随程序发的参考版，每次启动刷新 |
| `ItamiBen.sqlite3` | 程序自己记的东西：观测、轮次、设置、累计账本 |

## 周期提醒

`schedule` 表里的行，时刻用**标准 crontab**——Vixie 语义，含「日 / 周」那条 OR 规则。
一行带提醒文字，行尾还可以跟一个 `commands.md` 里的命令名。细节文件里写着。

到点时**同时**给你两样，这是故意的：

- 骨牌上那条提示条，保证**屏幕上一分钟内一定看得见**；
- **系统通知**，**一条事件一个、永远不合并**——提示条有硬高度上限、多出来的只剩一个 `+N`，
  **通知中心那一份才是不丢内容的**，而且关掉程序还翻得回来。

设置里的 Alarms 开关**只管响不响铃**，提醒本身永远会出。

## 闹钟，以及它到点的时候发生了什么

那根黄针就是一个普通的墙上闹钟，**跟专注判定毫无关系**。在钟面上滚滚轮设定；
它是**一次性**的，响完自己清掉；重启之后还在。

到点时：

**二选一，绝不叠加**——那个开关选的就是走哪一边：

1. **关着（默认）**：选定的系统音**响 4 遍**（专注相关的那三声只响 2 遍——它们各自都在
   屏幕上留下了一个看得回来的状态；闹钟响完什么都不留）。
2. **开着**（右键菜单的「Run command at alarm」，或设置里 Command 那张卡上写着
   `Ring` / `Run` 的开关）：跑 `alarmCommand` 这个设置**指名**的那条命令，
   **一声都不响**。响铃是「提醒你自己动手」，跑命令是「替你动手」，两件事不叠加。

这个开关**每次启动一律是关的**，从不持久化——那条命令多半是关机。

命令是表里的行，一个平台一列，闹钟**按名字**引用它：

```sql
INSERT INTO command (name, macos, windows) VALUES
  ('sleep', 'pmset sleepnow', 'rundll32.exe powrprof.dll,SetSuspendState 0,1,0');
INSERT INTO setting (key, value) VALUES ('alarmCommand', '"sleep"')
  ON CONFLICT(key) DO UPDATE SET value = excluded.value;
```

⚠️ **可执行的文本只住在 `command` 表里。** 闹钟和计划表都只存名字、不存正文，
所以「这台机器上有哪些命令能被自动跑」永远只要看一个地方。

⚠️ **那个开关每次启动都是关的。** 持久化它是事故：重启之后被上一个会话的关机命令拍死，
而你根本不知道它还开着。

设置窗口会把**到点真正会跑的那条命令原文**显示出来。这个值多半是关机命令，
**按下开关之前你有权知道按的是什么。**

## 环境要求

- 运行要 .NET 10 Runtime，编译要 SDK
- Windows 或 macOS

⚠️ **macOS 需要辅助功能授权才能读窗口标题。** 没有授权程序照样跑，但**只能读到程序名**，
所有按标题写的规则**静默地永不命中**。程序会在状态栏里告诉你，并给一个按钮直接打开那一页。
**不需要重启进程，下一拍就生效。Windows 不需要任何授权。**

## 编译与运行

```bash
dotnet build ItamiBen.slnx
dotnet test  ItamiBen.slnx
./run-macos.sh              # 编译 → 打成 .app → 签名 → 启动
./run-macos.sh --run-only   # 只启动，不编译不重签
```

⚠️ **macOS 上别用 `dotnet run`，也别直接跑 `bin/` 里的裸二进制。**
辅助功能授权按「应用」记账，裸二进制拿不到——症状是**只读得到应用名、读不到窗口标题**，
一半的规则从此静默失效。必须走 `run-macos.sh` 打出来的 `.app`。

## 发布

```bash
./pack-macos.sh             # → dist/ItamiBen-<版本>-macOS-<架构>.dmg
pwsh pack-windows.ps1       # → dist\ItamiBen-<版本>-win-x64.exe（需要 Inno Setup 6）
```

两边都是**依赖框架**的，目标机器上要先装好 .NET 10 Runtime。Windows 的安装包会自己检测
并提出替用户下载；macOS 的 `.dmg` 在 Read Me 里说明。版本号**只有一个出处**：
`Directory.Build.props` 的 `<Version>`。

✅ 两边现在都在真机上跑过了。`pack-windows.ps1` 和 `installer/ItamiBen.iss` 2026-09-18
第一次在 Windows 11 + Inno Setup 6.7.3 上走通：11MB 的按用户安装包，全程不弹 UAC，
装进 `%LOCALAPPDATA%\Programs\ItamiBen`，覆盖升级也干净。

## 觉得不对劲的时候

把相关那份配置文件丢给 AI，说一句你本来以为会怎样。每份文件都自带说明，
所以 AI 同时看得到**你要的是什么**和**程序会怎么理解它**。

要是答案是「我的规则从来没命中过」，`rules.md` 里写着怎么查出那个程序在你机器上
**到底叫什么**——它会让你开一轮、用一下那个程序，然后从红格里把真名读出来。

**没有任何命令要你敲，也没有任何东西要你记。**

## 名字

**Itami**（痛み）是痛，**Ben** 是 Big Ben——准时、响亮、没法跟它讲条件。

痛みを知らせる：**把痛告诉你**。不是施加痛苦——那些小时本来就已经没了；
只是不再让它们悄悄消失。这就是整个产品主张，所以名字本身就是主张。
